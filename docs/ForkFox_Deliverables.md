# ForkFox Deliverables (Deck + PDF)

## What was created
1. **Detailed branded strategy deck (HTML):**
   - `docs/ForkFox_Strategy_Deck.html`
2. **Full detailed plan (PDF):**

## Branding choices used
Based on review of `forkfox.ai` content and visual style:
- Dark/charcoal UI foundation
- Warm fox-orange primary accent
- Clean white text/data cards for contrast

Primary palette in deck:
- `#f26d21` (Fox Orange)
- `#ff9a3d` (Soft Orange)
- `#171a21` (Ink)
- `#222733` (Charcoal)
- `#f7f8fb` (Fog)

## How to view
- Open deck: `docs/ForkFox_Strategy_Deck.html` in any browser.
- Open PDF: `docs/ForkFox_Full_Detailed_Plan.pdf`.

```bash
python tools/generate_forkfox_pdf.py
```
